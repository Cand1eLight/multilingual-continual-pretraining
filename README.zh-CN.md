# 多语言持续预训练

这个项目研究一个 41.69M 参数的英文故事模型如何学习中文，以及中文训练
对原有英文能力和未训练葡语的影响。两组最终训练分别使用纯中文数据和
中文加少量英文回放数据，训练预算均为 1,200 次更新。

| 模型 | 中文 PPL | 英文 PPL | 葡语 PPL |
| --- | ---: | ---: | ---: |
| 基础模型 | 117,885.17 | 3.14 | 26,522.53 |
| 纯中文训练 | 4.80 | 7.07 | 214,567.28 |
| 中文 + 英文回放 | 5.05 | 2.86 | 121,860.09 |

上表使用每种语言相同的 32,640 个预测 token；PPL 越低越好。纯中文训练
显著降低中文 PPL，同时损害英文表现。加入 1,000 条英文故事后，英文
表现得到恢复，中文 PPL 有小幅上升。葡语只用于评测，两种训练均未改善
它的表现。

另外，我用四类提示词、六种解码设置和三个随机种子生成了 72 段英文
续写，比较多样性、重复和叙事连贯性；三个学习率采用相同的 80 次更新
预算，由中文开发集 PPL 选择最终学习率。

范围；固定 token PPL 与逐文档平均 PPL 使用不同的加权方式，报告中
分别列出。
